# Geo_UNI_Projects
This repository is a central database of the projects I've completed during my Bachelor's of Science in Geography at the Universität Heidelberg, Germany. Each subfolder has a separate project and some are even online, interactive maps that one can toggle and use.

## 1. Hausarbeit GDE
This project was part of the 1st semester introductory course "Exercise: Geo-Data Collection (Übung Geodatenerfassung)" wherein the chosen objective was to use GNSS to track all Vending Machines in the Old-City of Heidelberg. Our objective was easiest to display through an interactive online map. With such a map we can display the location of each machine clearly and users can call upon specific data to each location with pop-up bubbles. 

The Link to the interactive map is to be found here:
https://tardis-11.github.io/Geo_UNI_Projects/Hausarbeit_GDE/

This Project received a Grade of **1,0** (highest possible grade in German colleges)

## 2. 15min_stadt_fuer_alle
This Project was part of the course "GIS-Seminar: Climate Action and Sustainable Cities" wherein we learned how to use QGIS to answer and deal with multiple geographic questions regarding primarily mobility and climate change mapping.

Our project was to see the walkability of the district (Stadtteil) Mannheim-Neckarau is for its senior residents. We dealt with our Question as follows:

calculate how far seniors are truly willing to walk for different points of interest (POIs)
analyse the accessibilty of different POIs from each house and how far they are with regard to time.
analysing which street-networks are unbroken and of adequate quality to ensure that seniors with mobility issues still make it to their POI.
Mixing Accessibilty maps 2 and 3.

The Link to the paper is to be found here:
https://tardis-11.github.io/Geo_UNI_Projects/15min_stadt_fuer_alle/

This Project received a grade of **1,0**

## 3. Randvoll...?
This Directory is for a project part of the course "Exercise: Introduction to Remote Sensing" (Übung) from my 3rd Semester, wherein we calculated (using supervised classification methods) the growth of the urban area build-up of the city Kathmandu, Nepal over the last 20 years to calculate how it will grow in the following 20 years. We used ENVI 6.2 as well as QGIS for this project.

The Link to the paper is available here: 
https://tardis-11.github.io/Geo_UNI_Projects/Randvoll...%3F/

This Project received a Grade of 1,3.

## 4. GLP_STADT_KOETHEN
This directory is for a project out of the 4th Semester where a bunch of students went to the City of Köthen in Saxony-Anhalt to see how a mid sized city in Germany is planned and how a city with a large, aging population is dealing with the consequences of demographic change. We conducted Street-Side Interviews of many residents of the city within the city centre to understand what can be done to improve the city. This directory shows these results. This directory has the raw data from the interviews as well as a cleaned data-set and finally an HTML document with my statistical analysis of the interview.

An in-depth analysis of the interview responses is to be found here: https://tardis-11.github.io/Geo_UNI_Projects/GLP_STADT_KOETHEN/
