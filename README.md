# Geo_UNI_Projects
This repository is a central database of the projects I've completed during my Bachelor's of Science in Geography at the Universität Heidelberg, Germany. Each subfolder has a separate project and some are even online, interactive maps that one can toggle and use.

## 1. Hausarbeit GDE
This project was part of the 1st semester introductory course "Exercise: Geo-Data Collection (Übung Geodatenerfassung)" wherein the chosen objective was to use GNSS to track all Vending Machines in the Old-City of Heidelberg. Our objective was easiest to display through an interactive online map. With such a map we can display the location of each machine clearly and users can call upon specific data to each location with pop-up bubbles. 

The Link to the interactive map is https://tardis-11.github.io/Geo_UNI_Projects/Hausarbeit_GDE/
