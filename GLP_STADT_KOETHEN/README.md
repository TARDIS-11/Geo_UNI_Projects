# README
This directory is for a project out of the 4th Semester where a bunch of students went to the City of Köthen in Saxony-Anhalt to see how a mid sized city in Germany is planned and how a city with a large, aging population is dealing with the consequences of demographic change. 
We conducted Street-Side Interviews of many residents of the city within the city centre to understand what can be done to improve the city. This directory shows these results.
This directory has the raw data from the interviews as well as a cleaned data-set and finally an HTML document with my statistical analysis of the interview.

An in-depth analysis of the interview responses is to be found here:
https://tardis-11.github.io/Geo_UNI_Projects/GLP_STADT_KOETHEN/
