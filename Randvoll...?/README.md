# README
This Directory is for a project part of the course "Exercise: Introduction to Remote Sensing" (Übung) from my 3rd Semester, wherein we calculated (using supervised classification methods) the growth of the urban area build-up of the city Kathmandu, Nepal over the last 20 years to calculate how it will grow in the following 20 years.
We used ENVI 6.2 as well as QGIS for this project. 

The Link to this project is available here: https://tardis-11.github.io/Geo_UNI_Projects/Randvoll...%3F/

This Project received a Grade of **1,3**.
